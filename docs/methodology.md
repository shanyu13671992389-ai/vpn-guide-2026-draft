# 资料整理与选购比较方法

## 本文已经完成的工作

本项目以2026-10-28—29读取的官网、当前购买页、帮助文档和用户提供的商店截图整理20家服务。记录整期金额、付款周期、配额、重置条件、客户端入口和已知限制。各家日期及页面见SOURCES.md，结构化字段见data/product-plans.json。

页面内部有冲突时同时保留，例如精灵学院的价格和设备规则、星云重置日、极客云SSR说明、云猫TB与GB口径。未把其中一种写成已经消除争议的权益。

## 五个比较维度

| 维度 | 看什么 | 什么证据才有用 |
|---|---|---|
| 稳定性 | 连接中断、丢包、故障恢复 | 注明日期、地区、运营商和时段的重复观察 |
| 速度 | 延迟、下载、上传和实际应用 | 同条件测量；区分线路标称、套餐上限和实际结果 |
| 成本 | 整期金额、配额、周期、设备及额外费用 | 当期购买页及所选配置；促销需验证适用条件 |
| 隐私与规则 | 运营主体、日志、退款和共享限制 | 一手条款、审计原文及其覆盖范围，不能仅凭品牌判断 |
| 支持 | 系统、协议、教程和客服 | 当前教程及支持边界；响应时间需要实际记录 |

## 不代表已经完成的验证

本文没有完成统一网络下的20家节点测速、长期稳定性观察、隐私审计、退款或付款测试；阅读官网和取得邀请码不能替代这些验证。推荐顺序是编辑安排，不是综合测评分数。

## 之后补充实测时

每项结果注明测试日期、地区、运营商、接入方式、设备及客户端版本、所用套餐和节点、时段及方法。单次成功不写成长期保证；不同环境的结果分别记录，不直接拼成排名。不得公布个人订阅、凭据、支付信息或他人资料。

## 更新流程

收到价格或入口变更线索后，先核对一手页面，再同步JSON、正文表格和必要配图，最后写入CHANGELOG。不能确认的项目继续标明差异。当前没有自动监测、定时测速或自动发布服务。
